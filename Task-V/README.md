# Task V — Payment Transaction Management System

## Requirements
1. Create the `Payment` table.
2. Store payment mode, date, amount and status.
3. Manage successful, failed and pending transactions.
4. Analyze payment methods used by customers.
5. Generate payment transaction reports.

## SQL
The complete implementation is in `payment.sql`.

## Main Table
**Payment** — stores payment ID, order ID, payment mode, payment date, amount and transaction status.

## Reports
The SQL file includes transaction reports, successful/failed/pending summaries and payment-method usage analysis.
