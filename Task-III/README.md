# Task III – Seller and Inventory Management System

## Requirements
1. Create Seller and Inventory tables.
2. Establish relationships between sellers, products, and stock.
3. Maintain seller product information.
4. Track available and unavailable products.
5. Generate inventory status reports.

## Files
- `seller_inventory.sql` – seller/inventory tables, sample data, stock update, and status report.

## Relationships
- `Seller (1) -> (Many) Inventory`
- `Product (1) -> (Many) Inventory`
