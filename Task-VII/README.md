# Task VII — SQL Query Implementation

## Objective
To implement SQL queries for the e-commerce database and retrieve useful information from the stored data.

## Requirements

1. Perform SELECT, WHERE, ORDER BY, and DISTINCT queries.
2. Search products based on price, category, and availability.
3. Retrieve customer and product information.
4. Apply filtering conditions.
5. Generate basic business reports.

## SQL File

- `sql_queries.sql` — Contains all Task VII SQL queries and reports.

## Queries Covered

- Product information
- Customer information
- Product search
- Price and category filtering
- Product availability
- Sorting and filtering
- Basic business reports
