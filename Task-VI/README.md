# Task VI — Product Review and Rating Management System

## Requirements
1. Create `Review` and `Rating` tables.
2. Store customer feedback and ratings.
3. Retrieve product review details.
4. Calculate average product ratings using aggregate functions.
5. Identify highly rated products.

## SQL
The complete implementation is in `review_rating.sql`.

## Tables
- **Review** — stores customer reviews for products, including review date and feedback.
- **Rating** — stores customer ratings for products and links each rating to the related review.

## Operations and Reports
The SQL file includes table creation, sample customer feedback and ratings, review retrieval, average rating calculation using `AVG()`, and a report identifying highly rated products.
