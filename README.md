# E-Commerce Order Management System

Complete DBMS project organized task-wise.

## Tasks

### Task I — Requirement Analysis and Customer Database
Requirement analysis, customer database design and customer operations.

**Folder:** `Task-I/`

### Task II — Product and Category Management
Product and Category tables, primary/foreign keys, CRUD operations and category-wise reports.

**Folder:** `Task-II/`

### Task III — Seller and Inventory Management
Seller and Inventory tables, seller-product-stock relationships, availability tracking and inventory reports.

**Folder:** `Task-III/`

### Task IV — Order Management
Orders and Order_Details tables, order insertion/modification and customer order history reports.

**Folder:** `Task-IV/`

### Task V — Payment Transaction Management
Payment table, payment mode/date/amount/status, successful and failed transactions, payment analysis and transaction reports.

**Folder:** `Task-V/`

## SQL Execution Order

Run the SQL files in this order:

1. `Task-I/customer.sql`
2. `Task-II/product_category.sql`
3. `Task-III/seller_inventory.sql`
4. `Task-IV/orders.sql`
5. `Task-V/payment.sql`

Each task has its own README containing its requirements and implementation details.
