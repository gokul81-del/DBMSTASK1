# Task IV — Order Management System

## Requirements
1. Design `Orders` and `Order_Details` tables.
2. Manage customer product orders.
3. Store order date, quantity and total amount.
4. Perform order insertion and modification operations.
5. Generate customer order history reports.

## SQL
The complete implementation is in `orders.sql`.

## Tables
- **Orders** — order ID, customer, order date, total amount and order status.
- **Order_Details** — order detail ID, order, product, quantity, unit price and total price.

## Operations
The SQL file includes order creation, order-detail insertion, order modification and customer order history reporting.
